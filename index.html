AutoSRE

Open Source PyPI v0.2.2

An autonomous incident-response agent — the AI SRE that investigates like your best on-call engineer, but faster. It triages the alert, gathers evidence across Kubernetes state, Prometheus metrics and logs, tests competing hypotheses in parallel, and lands on a root cause with a confidence score. Target: 45-minute RCA down to under five.

Built on LangGraph with parallel sub-agents, episodic memory in SQLite so it recalls similar past incidents, and a hard human-in-the-loop gate before anything touches production.

LangGraph · Python · Kubernetes · Prometheus · Next.js · Datadog · PagerDuty
